# QPR2 subject Path conversion — isolated-build opt-in

Ordinary framework.jar patch, taken from the pinned CP41.260831.007.A3 GSI and
adapted to the original S942BXXS4BZIG framework without replacing other classes.
Adds both CaptureResult keys, extension ID 5, the actual FLOAT-array/Path
get/set methods, dispatch bridges and GetCommand/SetCommand registrations.
MOVE, LINE, QUAD, CONIC, CUBIC, CLOSE and null/empty behavior retain the QPR2
encoding. A follow-up rejects nonfinite values and fractional verbs instead of
letting float-to-int conversion reinterpret malformed input as a valid command.
Nonfinite output is rejected before writing metadata. Existing Samsung native
declarations remain.

Explicit opt-ins: UN1CA_QPR2_CAMERA_PATH=true and
UN1CA_QPR2_CAMERA_METADATA=true. The matching native schema must already be
present. Paradigm's One UI 9 test profile sets both opt-ins together. SDK-36
builds remain unchanged; to omit this experiment from a One UI 9 build, export
both UN1CA_QPR2_CAMERA_PATH=false and UN1CA_QPR2_CAMERA_METADATA=false.

This modifies the boot classpath. The staged JAR is ROM-only, not a standalone
APK or live-installable replacement. A complete build must invalidate/rebuild
the corresponding ART/boot-image cohort. That cohort is not generated by this
module's offline JAR compilation. Do not bind-mount this JAR onto a running ROM.

The codec does not compute a subject mask or provide a Camera2 SessionProcessor.
It has assembled-DEX fixtures with mocked Path/PathIterator and metadata storage;
physical Skia/ART/Camera2 behavior remains to be qualified.
